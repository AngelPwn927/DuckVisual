лаунчер на go потому что он собирается в один exe и все, никаких установщиков, весит мегов 8


1) сначала НЕ делай окно!! сначала сделай чтоб игра просто запускалась из консоли
я сначала начал с интерфейса и потом все переделывал, не надо так


2) качаем майн
- список версий тут: https://piston-meta.mojang.com/mc/game/version_manifest_v2.json
- там находишь свою версию (1.21.4 например) и качаешь ее json по ссылке
- в этом json вообще все есть:
    downloads.client  - сам jar игры
    libraries         - библиотеки, у них есть rules (смотри чтобы под windows подходило, а то накачаешь macos-овские)
    assetIndex        - звуки текстуры итд
    javaVersion       - какая джава нужна
    arguments         - аргументы запуска (у старых версий minecraftArguments одной строкой, бесит)
- ассеты качаются так: https://resources.download.minecraft.net/ПЕРВЫЕ2СИМВОЛАХЭША/ХЭШ
- качать надо параллельно, штук 8 потоков, иначе ассеты будут качаться вечность (их там тыщи)
- ОБЯЗАТЕЛЬНО проверяй sha1 у файлов, если битый - перекачивай. и если файл уже есть и хэш норм то не качай заново
- natives у старых версий (до 1.19) надо распаковывать в отдельную папку, у новых они просто как обычные либы

(смотри core/minecraft.go и core/download.go)


3) джава
юзеру ставить джаву самому - нет, никто не будет. качаем сами с adoptium:
https://api.adoptium.net/v3/binary/latest/21/ga/windows/x64/jre/hotspot/normal/eclipse
(вместо 21 нужная версия)
распаковал zip в runtime/java21 и все

какая джава под какой майн:
  до 1.16 -> 8
  1.17 -> 16
  1.18-1.20.4 -> 17
  1.20.5 и выше -> 21
но вообще проще брать из javaVersion в json версии, там прям написано

(core/java.go)


4) запуск
собираешь команду типо
java -Xmx4G -cp все.jar;через;точку;с;запятой  mainClass  --username Ник --version 1.21.4 --gameDir папка --assetsDir папка --assetIndex 19 --uuid ... --accessToken 0 --userType legacy

- в arguments там всякие ${auth_player_name} ${game_directory} - их надо заменить на свое
- чтоб черное окно консоли не вылазило - CREATE_NO_WINDOW (core/proc_windows.go)
- вывод игры пиши в лог файл!!! потом игроки будут кидать ошибки и без лога ты нифига не поймешь

на этом шаге уже должна запускаться чистая ванилла. если запустилось - ты молодец, дальше легче

(core/launch.go)


5) аккаунты
- оффлайн: просто ник. uuid делается как md5 от "OfflinePlayer:"+ник (версия 3). токен любой, хоть 0
- ely.by (если хочешь скины): POST на https://authserver.ely.by/auth/authenticate, получаешь токен,
  и в джаву добавляешь -javaagent:authlib-injector.jar=ely.by
- майкрософт лицуха - это гемор, надо регать приложение в azure и ждать пока mojang одобрит. я забил

(core/auth.go)


6) fabric + моды
- профиль фабрика: https://meta.fabricmc.net/v2/versions/loader/1.21.4/ВЕРСИЯЛОАДЕРА/profile/json
- его либы добавляешь к ванильным, mainClass берешь фабриковский
- моды качаем с modrinth, там апи без ключа:
  https://api.modrinth.com/v2/project/sodium/version?game_versions=["1.21.4"]&loaders=["fabric"]
  берешь первый файл. у мода есть dependencies - если required то их тоже качай, а то краш
- свой мод можно прям в exe вшить через go:embed и кидать в mods при каждом запуске
- запоминай какие моды поставил лаунчер (я в .duck-managed.json пишу), чтоб при обновлении не снести моды которые игрок сам закинул

(core/mods.go)


7) только теперь окно
- весь интерфейс это просто html страница, один файл ui/index.html (html+css+js вместе)
- вшиваешь через //go:embed ui/index.html
- открываешь:
    w := webview2.NewWithOptions(...)
    w.SetHtml(html)
    w.Run()
- связь js -> go: w.Bind("dlPlay", функция) и в js просто await dlPlay()
- go -> js (прогресс бар): w.Dispatch(func(){ w.Eval("onProgress(...)") })
- дизайн делай в браузере обычном, так быстрее, а функции dl... замокай заглушками

(ui_windows.go)


8) всякие фишки (по желанию)
- вкладка модов: поиск модринт /v2/search?query=...  , курсфордж только с апи ключом (console.curseforge.com, бесплатно)
- свой сервер в мультиплеере: файл servers.dat, он в формате NBT, там список servers с name и ip.
  я написал свой мини парсер nbt (core/nbt.go), там ничего сложного
- зайти сразу на сервер: --quickPlayMultiplayer ip:порт (1.20+) или --server ip --port порт для старых
- онлайн сервера в лаунчере: server list ping, это по tcp пакет handshake + пакет 0, в ответ json (core/servers.go)
- оптимизация (core/optimize.go):
    * моды sodium lithium ferritecore modernfix и тд
    * флаги g1gc нормальные
    * -XX:+AutoCreateSharedArchive - игра со второго раза грузится сильно быстрее, у меня было 88с -> 25с
    * пресеты графики через options.txt
    * приоритет процесса повыше
    * на ноутах реестр HKCU\Software\Microsoft\DirectX\UserGpuPreferences чтоб игра шла на нормальной видюхе а не встройке
- надпись в окне игры вместо "Minecraft" - это уже в моде делается, mixin на getWindowTitle


9) сборка exe
- иконка и инфа о файле:
    go run github.com/tc-hib/go-winres@v0.3.3 make
  (конфиг в winres/winres.json)
- сама сборка:
    GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -ldflags "-H windowsgui -s -w" -o "My Launcher.exe" .
- винда будет орать "windows защитила ваш компьютер" - это у всех без подписи. убрать только сертификатом
  (certum/sectigo, платно, бесплатно никак). пока что юзерам говоришь "подробнее -> выполнить в любом случае"

- проверь несколько версий: 1.8.9, 1.16.5, 1.20.1, 1.21.4 - у всех разная джава и разные аргументы, что-то по любому вылезет
- проверь на чистой винде где нет джавы вообще
