# 🦆 Duck Launcher

Лаунчер Minecraft с уже установленным **Duck Visual** (1.21.4) и любыми другими релизами от 1.8.9 до последнего.
Скачал `Duck Launcher.exe` → запустил → вошёл → **ИГРАТЬ**.

> Duck Launcher и Duck Visual не являются продуктами Mojang AB и не связаны с Mojang AB или Microsoft.
> Minecraft — товарный знак Mojang AB. Игровые файлы загружаются с официальных серверов Mojang.

Новости и поддержка: Telegram-канал [@DuckVisual](https://t.me/duckvisual)

## Что делает лаунчер

При первом нажатии «Играть» он сам скачивает всё нужное (≈ 600 МБ, один раз на версию):

| Что | Откуда |
|---|---|
| Java нужной версии (8 / 17 / 21 / 25, Eclipse Temurin JRE) | api.adoptium.net |
| Minecraft: клиент, библиотеки, ресурсы | серверы Mojang |
| Fabric Loader (последний стабильный) | meta.fabricmc.net |
| Fabric API + моды оптимизации | Modrinth |
| Duck Visual (только 1.21.4) | вшит прямо в .exe |
| authlib-injector (только для Ely.by) | authlib-injector.yushi.moe |

## Версии

Кнопка «Версия» рядом с «Играть»: все релизы от **1.8.9** до последнего, **Fabric** или **Vanilla**.
У каждой версии своя папка (`instances/<версия>-<загрузчик>`), миры и настройки не смешиваются.
Duck Visual есть только на **1.21.4 + Fabric** (значок DUCK).

## Моды (Modrinth и CurseForge)

Вкладка **«Моды»**: поиск по каталогу Modrinth или CurseForge, сразу только моды для **выбранной версии на Fabric**.
«Установить» скачивает последнюю подходящую сборку **вместе с обязательными зависимостями** в папку `mods` этой версии
(файлы проверяются по SHA-1). «Мои моды» — что поставлено, там же удаление.
Моды, которые лаунчер ставит сам (Fabric API, Sodium и т.д.), повторно не скачиваются.

- **Modrinth** работает сразу.
- **CurseForge** отдаёт каталог сторонним лаунчерам только по API-ключу. Он бесплатный: войти на
  [console.curseforge.com](https://console.curseforge.com/) → API Keys → скопировать → вставить в **Настройки → CurseForge**.
  Если автор мода запретил скачивание в сторонних лаунчерах, лаунчер скажет об этом — такой мод качается со страницы мода.

## Серверы

Сервер **Duck Server** (`n1.pg19.su:25795`) автоматически добавляется первым в «Сетевую игру» на любой версии
(свои серверы игрока не трогаются). Вкладка **«Серверы»** показывает онлайн, пинг и MOTD,
кнопка «Играть на сервере» запускает игру и сразу подключает к серверу.
Список серверов — `core/servers.go` (`Servers`).

## Оптимизация

**Моды оптимизации** (Fabric; каждый можно выключить, ставятся сами вместе со своими библиотеками,
если мода нет для выбранной версии — пропускается):

| Группа | Моды |
|---|---|
| FPS и графика | Sodium, Sodium Extra, Reese's Sodium Options, MoreCulling, EntityCulling, ImmediatelyFast, BadOptimizations, Dynamic FPS |
| Процессор и мир | Lithium, ScalableLux, Clumps, Noisium, C2ME (бета, по умолчанию выключен) |
| Память и запуск | FerriteCore, ModernFix, Ksyxis |
| Сеть | Krypton |

Все вместе проверены на 1.21.4 с Duck Visual (все 61 функция включены) — без конфликтов.

**Профиль графики** (применяется при следующем запуске, потом можно менять в игре):
- **Авто** — до 6 ГБ ОЗУ «Максимум FPS», иначе «Баланс»;
- **Максимум FPS** — дальность 6, быстрая графика, быстрая листва и погода (Sodium), без облаков, теней, сглаживания света, виньетки и блюра меню, минимум частиц, без лимита FPS и vsync;
- **Баланс** — дальность 10; **Качество** — дальность 16; **Не трогать**.

**Система:**
- **Высокий приоритет игры** (Windows) — процесс игры с приоритетом «выше среднего»: меньше фризов от фоновых программ.
- **Мощная видеокарта** (Windows) — игре ставится настройка Windows «Высокая производительность», ноутбуки запускают её на NVIDIA/AMD, а не на встроенной графике.
- **Быстрый запуск** — Java-кэш классов (AppCDS): в тесте запуск 1.21.4 с модами ускорился с 88 до 25 секунд со второго раза.
- **Флаги Java** — настроенный G1 (короткие паузы сборщика мусора, большой young gen, дедупликация строк), IPv4 для быстрого подключения.
- **Память «Авто»** — под объём ОЗУ (4 ГБ ПК → 1.5 ГБ игре, 8 → 2.5, 16 → 4).
- **После запуска** лаунчер сворачивается (или закрывается) и не занимает память.

Все файлы проверяются по контрольным суммам. Следующие запуски — сразу.

Всё хранится в `%APPDATA%\.ducklauncher` (игра — в `minecraft`, моды — в `minecraft\mods`, туда можно добавлять свои моды для 1.21.4 Fabric).

## Вход

- **Без лицензии** — просто ник (латиница/цифры/_ , 3–16 символов). Для серверов с оффлайн-режимом.
- **Ely.by** — логин/e-mail и пароль (при 2FA: `пароль:код`). Скин и плащ с Ely.by, вход на серверы с поддержкой Ely.by через authlib-injector.

Пароль нигде не сохраняется — хранится только токен входа в `launcher.json`.

## Настройки

Профиль графики, приоритет, видеокарта, быстрый запуск, память (Авто или вручную), моды оптимизации, полноэкранный режим, размер окна, язык игры,
что делать после запуска (оставить / свернуть / закрыть), свои аргументы Java, кнопки «Папка игры / Моды / Скриншоты / Логи / Лаунчер».

## Предупреждение Windows (SmartScreen)

Окно «Windows защитила ваш компьютер» появляется у **любой** программы без цифровой подписи, это не вирус:
нажми **«Подробнее» → «Выполнить в любом случае»**.

Убрать его насовсем можно только подписью сертификата разработчика (это платно, бесплатных вариантов, которые работают со SmartScreen, нет):

| Вариант | Цена | Что даёт |
|---|---|---|
| Сертификат подписи кода (Certum, Sectigo, SSL.com) | ~25–300 $/год | «Неизвестный издатель» меняется на твоё имя, предупреждение пропадает после набора репутации (загрузок) |
| EV-сертификат | ~300–600 $/год | предупреждение пропадает сразу |
| Azure Trusted Signing | ~10 $/мес | доступен не во всех странах |

Когда сертификат будет: `DUCK_SIGN_PFX=cert.pfx DUCK_SIGN_PASS=пароль ./build.sh` — exe подпишется сам (нужен `osslsigncode`).
Если Защитник Windows вдруг удалит файл как ложное срабатывание — отправь exe на проверку:
[microsoft.com/wdsi/filesubmission](https://www.microsoft.com/wdsi/filesubmission) (бесплатно, обычно за 1–3 дня убирают).

## Требования

Windows 10/11 x64. Окно лаунчера использует **Microsoft Edge WebView2** — он встроен в Windows 11; на Windows 10 лаунчер сам предложит его скачать, если нет.

## Сборка

```sh
./build.sh        # нужен Go 1.24+
```

Результат: `dist/Duck Launcher.exe`. Есть консольный режим (и Linux-сборка) для проверки:
`ducklauncher -cli -name Nickname -version 1.20.1 -loader fabric -weak -join n1.pg19.su:25795`.
