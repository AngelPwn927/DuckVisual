# 🦆 Duck Visual

Визуалы для Minecraft 1.21.4 и Duck Launcher, который ставит всё сам. Бесплатно.

**📥 Скачать:** [последний релиз](https://github.com/AngelPwn927/DuckVisual/releases/latest) — `DuckLauncher.exe` (Windows 10/11).
**📢 Новости:** [t.me/duckvisual](https://t.me/duckvisual) · **⭐ Поддержать:** [t.me/duckvisual/2](https://t.me/duckvisual/2)

| Папка | Что это |
|---|---|
| [`DuckVisual`](DuckVisual) | мод для Fabric 1.21.4: 61 функция, своё меню, HUD, эффекты (Java) |
| [`DuckLauncher`](DuckLauncher) | лаунчер: Java, Minecraft, Fabric, моды для FPS, каталог модов, серверы (Go + WebView2) |
| [`DuckSite`](DuckSite) | сайт проекта (один HTML-файл) |
| [`DuckBot`](DuckBot) | Telegram-бот для донатов звёздами (Go) |
