# 🦆 Duck Bot — донаты звёздами в Telegram

Бот публикует в канал пост «Поддержать Duck Visual» с кнопками:

- **⭐ Поддержать создателя** — открывает бота, там можно выбрать сумму или ввести свою;
- **⭐ 50 / ⭐ 100 / ⭐ 250** — сразу открывают окно оплаты звёздами.

После оплаты бот пишет человеку «спасибо», а тебе — уведомление о донате. Все донаты записываются в `donations.jsonl`.

> Бот должен работать **всё время**: при оплате Telegram спрашивает бота «можно принять?»,
> и если бот выключен — платёж не пройдёт. Поэтому его держат на сервере (VPS), а не на домашнем ПК.

## 1. Создай бота
1. Открой **@BotFather** → `/newbot` → придумай имя (`Duck Visual Donate`) и username (`duckvisual_donate_bot`).
2. BotFather пришлёт **токен** вида `123456:ABC...`. **Никому его не показывай** — с ним можно управлять ботом.
3. Там же: `/setuserpic` — поставь аватарку (утку), `/setdescription` — «Донаты для Duck Visual».

## 2. Добавь бота в канал
Канал → Управление → **Администраторы** → Добавить → найди своего бота → оставь право **«Публикация сообщений»**.

## 3. Настрой
1. Скопируй `config.example.json` в `config.json`.
2. Впиши `token`.
3. Узнай свой id: запусти бота (шаг 4), напиши ему `/id`, впиши число в `adminId`, перезапусти.

| Поле | Что это |
|---|---|
| `token` | токен от @BotFather |
| `channel` | твой канал, `@duckvisual` |
| `adminId` | твой id — только ты сможешь публиковать пост и смотреть статистику |
| `amounts` | суммы на кнопках |
| `cover` | картинка для поста (`cover.png` уже лежит рядом) |
| `contact` | куда писать, если проблема с оплатой |

## 4. Запусти
- **Windows (для проверки):** положи рядом `duckbot.exe`, `config.json`, `cover.png` и запусти `start.bat`.
- **Сервер (Linux VPS):**
  ```sh
  sudo mkdir -p /opt/duckbot && sudo cp duckbot-linux config.json cover.png /opt/duckbot/
  sudo useradd -r -s /usr/sbin/nologin duckbot && sudo chown -R duckbot /opt/duckbot
  sudo cp duckbot.service /etc/systemd/system/ && sudo systemctl enable --now duckbot
  journalctl -u duckbot -f   # логи
  ```
  Бот сам перезапустится после ошибки или перезагрузки сервера.

## 5. Опубликуй пост
Напиши боту **`/post`** — он опубликует пост с обложкой и кнопками в канал. Закрепи его.
Старый пост «поставь ⭐» можно удалить или оставить — звёздные реакции тоже работают.

## Команды
| Команда | Кто | Что делает |
|---|---|---|
| `/start`, `/donate` | все | выбор суммы доната |
| `/terms` | все | условия: это добровольный донат, ничего не продаётся |
| `/paysupport` | все | куда писать, если проблема с оплатой (Telegram требует эту команду у ботов со звёздами) |
| `/id` | все | показать свой id |
| `/post` | админ | опубликовать пост с кнопками в канал |
| `/stats` | админ | сколько донатов и звёзд |
| `/refund <id> <chargeId>` | админ | вернуть звёзды (id и chargeId приходят в уведомлении о донате) |

## Где звёзды
Звёзды копятся на балансе **бота**: @BotFather → твой бот → **Balance** (или в профиле бота → «Звёзды»).
Их можно тратить на рекламу канала в Telegram. Вывод в деньги — через Fragment, только после проверки личности (18+).
