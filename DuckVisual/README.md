# 🦆 Duck Visual — 1.21.4

Клиентский визуальный мод для Minecraft **1.21.4** (Fabric) в стиле Pulse Visual:
ClickGUI, HUD, China Hat, Jump Circles, Trails, Target ESP, Hit Particles, кастомный прицел
и многое другое. Мод полностью клиентский, на сервер ничего не отправляет.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для **1.21.4** (0.16.10+).
2. Положите в `.minecraft/mods`:
   - `duck-visual-1.0.0.jar` (из `build/libs` после сборки)
   - [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.4
3. Запустите игру и нажмите **Right Shift**.

## Управление в меню

| Действие | Кнопка |
|---|---|
| Открыть / закрыть меню | `Right Shift` (можно перебиндить у модуля ClickGui) |
| Включить / выключить модуль | ЛКМ по карточке |
| Открыть настройки модуля | ПКМ по карточке |
| Забиндить модуль | СКМ по карточке → нажать клавишу (`Esc`/`Backspace` = убрать бинд) |
| Переключить режим | ЛКМ — вперёд, ПКМ — назад |
| Двигать HUD | Зажать ЛКМ на элементе HUD при открытом меню |
| Поиск | Поле `Search...` внизу слева |
| Описание функций | Вкладка **Описание** в меню или кнопка **?** на карточке модуля |
| Freelook | Зажать Left Alt |
| HUD-редактор | При открытом меню тащить элементы HUD, они прилипают к центру и краям (Shift — без прилипания) |
| Сменить цвета | Вкладка **Palette** в меню — клик по палитре (ПКМ по Custom — свои цвета) |
| Бинд на кнопку мыши | Начать бинд и нажать колесо / боковую кнопку мыши |
| Бинд слотов хотбара | Модуль CustomHotbar → ПКМ → Slot 1..9 → нажать клавишу (ПКМ по бинду — сброс) |

Конфиг сохраняется автоматически в `.minecraft/config/duckvisual.json`.

## Модули

**Visuals**
- **ChinaHat** — конус-шляпа над головой (градиент темы, обводка, на других игроках).
- **JumpCircles** — круги при прыжке (Glow / Ring / Wave).
- **Trails** — след за игроком (Ribbon / Line / Orbs).
- **TargetESP** — подсветка цели (Ghosts / Circle / Marker / Souls), краснеет при ударе.
- **HitParticles** — частицы при ударе (Orbs / Stars / Hearts / Cubes) с физикой.
- **HitColor** — цвет «покраснения» мобов при уроне (цвет темы или свой).
- **Arrows** — стрелки вокруг прицела на ближайших игроков.
- **Crosshair** — кастомный прицел (Cross / Circle / Dot), динамика и кулдаун атаки.
- **ViewModel** — позиция и размер предметов в руках.
- **SwingAnimation** — анимации удара (Smooth / Block / Slide / Spin / Punch / Down) и скорость.
- **AspectRatio** — растянутое разрешение.
- **NoRender** — убрать тряску при уроне, огонь, тыкву, тошноту, боссбар, скорборд, иконки эффектов.
- **Zoom** — зум на зажатую клавишу (C / V / Z / X / Alt / Mouse 4), колесо мыши меняет приближение.
- **BlockOverlay** — красивая обводка блока под прицелом с заливкой и плавным перемещением.
- **BoxESP** — боксы вокруг игроков/мобов/животных (Box / Filled / Corners) + полоска HP.
- **Tracers** — линии от прицела к игрокам (цвет по дистанции или по теме).
- **HitSounds** — звук при ударе (Bell / Pling / Orb / Chime / Arrow).
- **HitBoxes** — красивые хитбоксы как на F3+B: цвет темы/белый/по HP, линия глаз, направление взгляда, заливка, сквозь стены (только визуал).
- **CustomModels** — замена модели игрока: Duck / Amogus / Rabbit / Penguin, с анимацией ног и головы, на себе или на всех.
- **Trajectories** — траектория и точка падения снаряда в руке (лук, арбалет, трезубец, жемчуг, снежки, яйца, зелья, пузырьки опыта) + траектории снарядов в полёте; красным, если попадёт в сущность.
- **DamageIndicators** — всплывающие цифры урона/лечения над сущностями, твои криты выделены жёлтым с «!».
- **CritIndicator** — индикатор у прицела, когда следующий удар будет критом, вспышка «CRIT» и счётчик критов.
- **HealthTags** — полоска HP и число над головами игроков/мобов.
- **Freelook** — зажми Alt (настраивается) и крути камеру вокруг себя, персонаж идёт прямо.
- **GlowESP** — неоновая обводка игроков/мобов/предметов сквозь стены в цвете темы.
- **Nametags** — новые ники: HP, пинг, дистанция, броня с прочностью и предмет в руке.
- **TotemCounter** — счётчик снесённых тотемов (уведомление, чат, звук).
- **ItemPhysics** — выброшенные предметы лежат плашмя на земле.
- **MotionBlur** — размытие в движении (HUD не размывается).
- **HandTint** — рука и предмет в руке подсвечиваются цветом темы.
- **Hitmarker** — крестик-хитмаркер при ударе, красный при крите.
- **TargetCircle** — круг дистанции удара вокруг цели + расстояние.
- **KillEffects** — молния, частицы и звук, когда твоя цель умирает, + счётчик убийств.

**Hud**
- **Watermark** — лого Duck Visual, ник, FPS, пинг, время.
- **ArrayList** — список включённых модулей с анимацией.
- **Keybinds** — список биндов.
- **Potions** — активные эффекты зелий.
- **TargetHud** — информация о цели: голова, HP-бар, броня, частицы.
- **Information** — координаты (+ координаты Незера), скорость, сервер.
- **Notifications** — уведомления о включении/выключении модулей.
- **ArmorHud** — броня и её прочность в процентах.
- **CustomHotbar** — новый хотбар со скруглением и плавным выбором слота + **бинд на каждый слот** (клавиша или кнопка мыши).
- **LowHealth** — красная пульсирующая виньетка и сердцебиение при низком HP.
- **CombatInfo** — счётчик комбо и дистанция последнего удара (reach).
- **TabList** — новый Tab: головы игроков, цветной пинг, скругленная панель.
- **ScoreboardHud** — новый скорборд справа.
- **Music** — что сейчас играет: обложка, название (бегущая строка), исполнитель, источник, прогресс и эквалайзер. Бинды Play/Pause, Next, Previous.
  - **Windows 10/11** — через системный медиа-центр Windows (то же, что в окне громкости): браузеры Chrome / Edge / Firefox / Opera / Яндекс Браузер / Brave (YouTube, YouTube Music, SoundCloud, Яндекс Музыка, VK Музыка, Deezer и т.д.), Spotify, приложение Яндекс Музыки, Apple Music, AIMP, foobar2000, MusicBee, Медиаплеер Windows и любые программы, которые показывают трек в окне громкости.
  - **Linux** — через `playerctl` (любой MPRIS-плеер, включая браузеры).
  - **macOS** — Spotify и Apple Music.
- **Cooldowns** — кулдауны предметов (жемчуг, яблоки, щит, заряды ветра).

**World**
- **Fullbright** — полная яркость.
- **TimeChanger** — время суток на клиенте (фикс. или цикл).
- **WorldParticles** — светящиеся частицы вокруг (Fireflies / Snow / Rise).
- **CustomSky** — звёздное небо с северным сиянием в цветах темы (Night / Aurora).
- **ChunkAnimator** — чанки плавно выезжают снизу (или падают сверху) при прогрузке. С Sodium не работает (Sodium рисует чанки по-своему), но и не мешает запуску.
- **BreakEffects** — светящиеся частицы и вспышка при ломании блока.
- **WorldColor** — окрашивает небо, туман и облака в цвет темы или свой.

**Misc**
- **Theme** — цвета клиента: Gradient / Static / Rainbow, **26 готовых палитр** (Duck, Sunset, Ocean, Purple, Mint, Cherry, Sky, Lime, Pink, Aqua, Fire, Lavender, Blood, Gold, Ice, Neon, Forest, Royal, Peach, Candy, Toxic, Love, Mono, Rose, Coral, Emerald) или свои цвета.
- **ClickGui** — бинд меню, размытие и затемнение фона, описания.
- **CustomFont** — плавный шрифт Montserrat для HUD и меню (лицензия SIL OFL 1.1, файл `licenses/Montserrat-OFL.txt`).
- **MinecraftUI** — весь интерфейс Minecraft в стиле Duck Visual: шрифт Montserrat в меню, кнопках, чате и настройках; тёмные скруглённые кнопки с полоской цвета темы и подсветкой при наведении; слайдеры с заливкой в цвете темы. Текст в мире (таблички, ники) по умолчанию остаётся ванильным (настройка «World Text Font»).
- **MainMenu** — своё анимированное главное меню Duck Visual.
- **ChatTweaks** — время у сообщений, склейка повторов «(x3)», длинная история чата.

## Команды в чате

| Команда | Что делает |
|---|---|
| `.help` | список команд |
| `.toggle <модуль>` | включить/выключить |
| `.bind <модуль> <клавиша>` / `.unbind <модуль>` | бинд |
| `.set <модуль> <настройка> <значение>` | изменить настройку, напр. `.set Zoom Factor 6` |
| `.config save/load/delete <имя>`, `.config list` | профили конфигов (то же во вкладке **Configs** в меню) |
| `.modules` | список модулей |

## Совместимость

Проверено вместе с **Sodium 0.6.13** и **Iris 1.8.8** (1.21.4). Если другой мод перехватывает тот же код, соответствующая функция Duck Visual тихо отключается вместо краша.

## Сборка

Нужна Java 21.

```bash
./gradlew build
```

Готовый мод: `build/libs/duck-visual-1.0.0.jar`.

Всего модулей: **61**. Готовая сборка лежит в [`release/duck-visual-1.0.0.jar`](release/duck-visual-1.0.0.jar).
