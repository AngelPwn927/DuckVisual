Вопросы

Частые вопросы

Нужна лицензия Minecraft?

Нет. Можно играть по нику на серверах без проверки лицензии (их большинство) или войти через Ely.by. Вход через Microsoft пока не поддерживается.

Почему Windows ругается при запуске?

Так Windows реагирует на любую программу без платного сертификата разработчика. Это не вирус: нажми «Подробнее» и «Выполнить в любом случае». Код лаунчера открыт на GitHub.

Пойдёт на слабом ноутбуке?

Да. Включи профиль «Максимум FPS» в настройках, лаунчер сам поставит моды оптимизации и запустит игру на дискретной видеокарте, если она есть. Хватит 4 ГБ ОЗУ.

Duck Visual есть на других версиях?

Пока только на 1.21.4 с Fabric. На остальных версиях лаунчер запускает игру с модами оптимизации, без визуалов.

Меня не забанят за Duck Visual?

Duck Visual меняет только картинку у тебя на экране и не даёт преимуществ вроде увеличенных хитбоксов. Но правила у серверов разные, поэтому читай правила своего сервера.

Куда лаунчер ставит игру?

В папку %APPDATA%\.ducklauncher. Её можно открыть из настроек лаунчера: там же моды, скриншоты и логи.
