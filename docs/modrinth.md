## Description (English)

```markdown
# 🦆 Duck Visual

Stylish **client-side** visuals for Minecraft **1.21.4** (Fabric). 68 modules, all configurable and bindable, in a macOS-style glass menu. Capes, masks and skins from the duckvisual.ru wardrobe. Press **Right Shift** to open the menu.

![Menu](https://raw.githubusercontent.com/AngelPwn927/DuckVisual/main/docs/images/menu.jpg)

## Features
- **Combat visuals:** TargetESP (Ghosts / Circle / Marker / Souls), TargetHud, Trajectories, CritIndicator, DamageIndicators, Hitmarker, HitParticles, KillEffects, TargetCircle
- **Players & world:** Nametags, HealthTags, GlowESP, BoxESP, HitBoxes (visual only), Tracers, ChinaHat, JumpCircles, CustomModels (duck, amogus, rabbit, penguin), CustomSky with aurora, WorldParticles, WorldColor
- **HUD:** Watermark, ArrayList, Keybinds, Potions, ArmorHud, Cooldowns, TabList, Scoreboard, CustomHotbar with slot binds, **Music HUD** (browser, Spotify and other players)
- **Style:** 26 colour palettes, smooth Montserrat font, Duck-styled Minecraft menus, animated main menu
- **Camera:** Freelook, Zoom, MotionBlur, ViewModel, SwingAnimation

Everything is visual only: the mod changes what **you** see and sends nothing to the server.

## Compatibility
Tested with Sodium, Iris, Lithium, FerriteCore, ImmediatelyFast, EntityCulling and ModernFix.

## Duck Launcher
Want it all set up in one click? **[Duck Launcher](https://github.com/AngelPwn927/DuckVisual/releases/latest)** installs Java, Minecraft, Fabric, Duck Visual and 17 performance mods by itself.

News and support: [t.me/duckvisual](https://t.me/duckvisual)

*Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.*
```

# 🦆 Duck Visual

Красивые **клиентские** визуалы для Minecraft **1.21.4** (Fabric). 68 функций, всё настраивается и биндится, меню в стиле macOS. Плащи, маски и скины из гардероба duckvisual.ru. Меню — на **Right Shift**.

- **Бой:** TargetESP, TargetHud, траектории снарядов, индикатор крита, урон над мобами, хитмаркер, частицы и эффекты убийства

- **HUD:** вотермарка, список модулей, бинды, зелья, броня, кулдауны, новый Tab, хотбар с биндами слотов, **Music HUD** — трек из браузера, Spotify и других плееров

- **Камера:** Freelook, Zoom, MotionBlur, ViewModel, анимации удара

Мод только меняет картинку у тебя на экране и ничего не отправляет на сервер.
